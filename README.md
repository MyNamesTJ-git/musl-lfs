# musl-lfs
This is going to be a framework for building a alpine-like minimal base linux from scratch system. It will have instructions for making a usable system, along with scripted blueprints for simple, redundant tasks.

# THIS WILL TAKE A LONG TIME TO BE FINISHED, IF IT EVER IS. I AM NOT PROMISING THAT THIS WILL AMOUNT TO ANYTHING IN THE FUTURE.
at the moment, this project is in planning. at the moment, the only framework is that this is going to be a musl based system with runit as the init. there will me similaraties to projects such as Alpine linux (mostly in package choices) and Void Linux (runit and use as a reference)
