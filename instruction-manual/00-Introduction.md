# THIS IS INCOMPLETE
This is a project that has multiple inspirations. I have seen many amazing desktops and other linux builds in places like r/linuxfromscratch and want to hop into the "fun".

However, I wanted to put a twist, I wanted a minimal base to branch off of, something that can compile quickly and be ready for BLFS in less than an hour.

My primary inspirations are as follows, [jlxip](https://www.youtube.com/@jlxip) for making a minimal LFS speedrun that used a very small lfs system to get a sub-5:30 lfs system. I also am going to take much inspiration from [Void Linux](https://voidlinux.org/) and [Alpine linux](https://alpinelinux.org/), and the very obvious one is [LinuxFromScratch.org](https://linuxfromscratch.org/).

The end goal is to have a linux system that runs on runit, with the musl-libc and busybox coreutils. This will produce a minimal, quick to compile baseline for any BLFS projects that someone (likely only myself) may want to do.

This will likely have excerpts from the LFS handbook or the respective wiki from which the excerpt is from.
